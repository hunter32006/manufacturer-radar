# v1.2 多渠道采集

所有渠道只提供候选。程序实际读取企业详情页，识别完整厂家名称、相关主营及生产依据后，才创建厂家卡片。目录、地图商户、短视频昵称、导入表格和搜索摘要都不能单独证明厂家身份。

| 渠道 | 使用方式 | 接入条件 |
| --- | --- | --- |
| 百度、搜狗、360、Bing、头条、神马 | 公开搜索页，每个最多前3页 | 网站可能要求验证；状态如实记录 |
| 中国制造网、八方资源网、供应商网、慧聪网、百度爱采购、1688 | 平台公开搜索或目录，跟进企业详情 | 部分平台需普通浏览器登录或验证；不是每次都能自动读取 |
| 公开展商、政府工厂名录 | 内置公开入口，也可添加HTML/文本PDF链接 | 最多3个页面/附件；按产品关键词筛选线索 |
| 高德、百度地图 | 官方Web服务API，每页20条、最多3页 | 自己的密钥、城市及覆盖此次采集/存储/导出的授权 |
| CSV、XLSX、TXT、PDF、HTML、JSON | 本地文件或粘贴名单/链接，先预览再识别 | 每次20MB、1000行、最多100条线索；扫描PDF需先OCR |
| 抖音、快手、受限的搜索/B2B页面 | 浏览器辅助，读取当前页面 | 已安装Chrome或Edge；正常登录或手动验证；企业主体全称需明确 |

“采集渠道”调整开关与总时限。“导入名单/链接”提供Excel模板。“浏览器采集”会打开软件自己的浏览器窗口，用户进入搜索结果或企业资料页后点击读取；不会连接个人浏览器或导入其Cookie。需要进入具体详情页时，可在该窗口正常点击，再读取当前页。软件退出时关闭自己的浏览器，专用会话保存在软件数据目录。

地图密钥仅存在本次运行内存，不存入历史或导出。地图商户评分不转成厂家评分。只有名称精确匹配已核实厂家时，外部名单/地图中的电话才附到资料，并标注原始来源、归属待核实；不获得详情页电话加分。

只有名称的线索，每轮最多20家按完整名称搜索官网，每家仅第1页，仍需进入详情核实。没有可用搜索引擎时保留在线索记录，不作为厂家。所有来源共享最多120个候选页面的核实上限。默认总时限120秒，搜索发现最多30%，名称补查最多到45%，其余用于详情识别及负面补查；渠道较多时可调至180或300秒。

“采集记录”分开显示网页处理原因、渠道状态、原始名单和日志。没有结果、受限、超时、额度不足或未识别都不补造厂家信息。历史支持旧版数据；CSV/XLSX/JSON导出包含厂家链接和可追溯证据，XLSX增加原始渠道、发现来源、名称补查实际查询等列。

本功能没有付费数据服务账号，没有破解验证码、接口权限或登录限制。浏览器中的企业认证标签也是页面公开信息，不能代替工商资质核验。负面提示与评分仅作筛选参考，不能当作事实认定或信用评级。

地图接口与权限资料：[高德](https://lbs.amap.com/api/webservice/guide/api/search/)、[百度](https://lbsyun.baidu.com/docs/webapi?title=placev3%2Fguide%2Fwebservice-placeapiV3%2FinterfaceDocumentV2)。地图实际账户权限和额度需在用户自己的平台账户核对。
