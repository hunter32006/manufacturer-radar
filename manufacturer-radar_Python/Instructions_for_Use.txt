厂商雷达 v1.2.0 多渠道厂家识别版

# v1.2 多渠道采集

所有渠道只提供候选。程序实际读取企业详情页，识别完整厂家名称、相关主营及生产依据后，才创建厂家卡片。目录、地图商户、短视频昵称、导入表格和搜索摘要都不能单独证明厂家身份。

| 渠道 | 使用方式 | 接入条件 |
| --- | --- | --- |
| 百度、搜狗、360、Bing、头条、神马 | 公开搜索页，每个最多前3页 | 网站可能要求验证；状态如实记录 |
| 中国制造网、八方资源网、供应商网、慧聪网、百度爱采购、1688 | 平台公开搜索或目录，跟进企业详情 | 部分平台需普通浏览器登录或验证；不是每次都能自动读取 |
| 公开展商、政府工厂名录 | 内置公开入口，也可添加HTML/文本PDF链接 | 最多3个页面/附件；按产品关键词筛选线索 |
| 高德、百度地图 | 官方Web服务API，每页20条、最多3页 | 自己的密钥、城市及覆盖此次采集/存储/导出的授权 |
| CSV、XLSX、TXT、PDF、HTML、JSON | 本地文件或粘贴名单/链接，先预览再识别 | 每次20MB、1000行、最多100条线索；扫描PDF需先OCR |
| 抖音、快手、受限的搜索/B2B页面 | 浏览器辅助，读取当前页面 | 已安装Chrome或Edge；正常登录或手动验证；企业主体全称需明确 |

“采集渠道”调整开关与总时限。“导入名单/链接”提供Excel模板。“浏览器采集”会打开软件自己的浏览器窗口，用户进入搜索结果或企业资料页后点击读取；不会连接个人浏览器或导入其Cookie。需要进入具体详情页时，可在该窗口正常点击，再读取当前页。软件退出时关闭自己的浏览器，专用会话保存在软件数据目录。

地图密钥仅存在本次运行内存，不存入历史或导出。地图商户评分不转成厂家评分。只有名称精确匹配已核实厂家时，外部名单/地图中的电话才附到资料，并标注原始来源、归属待核实；不获得详情页电话加分。

只有名称的线索，每轮最多20家按完整名称搜索官网，每家仅第1页，仍需进入详情核实。没有可用搜索引擎时保留在线索记录，不作为厂家。所有来源共享最多120个候选页面的核实上限。默认总时限120秒，搜索发现最多30%，名称补查最多到45%，其余用于详情识别及负面补查；渠道较多时可调至180或300秒。

“采集记录”分开显示网页处理原因、渠道状态、原始名单和日志。没有结果、受限、超时、额度不足或未识别都不补造厂家信息。历史支持旧版数据；CSV/XLSX/JSON导出包含厂家链接和可追溯证据，XLSX增加原始渠道、发现来源、名称补查实际查询等列。

本功能没有付费数据服务账号，没有破解验证码、接口权限或登录限制。浏览器中的企业认证标签也是页面公开信息，不能代替工商资质核验。负面提示与评分仅作筛选参考，不能当作事实认定或信用评级。

地图接口与权限资料：[高德](https://lbs.amap.com/api/webservice/guide/api/search/)、[百度](https://lbsyun.baidu.com/docs/webapi?title=placev3%2Fguide%2Fwebservice-placeapiV3%2FinterfaceDocumentV2)。地图实际账户权限和额度需在用户自己的平台账户核对。


原有功能说明：
厂商雷达 v1.1.0 — Windows 便携版

一、启动
将整个压缩包解压到可写文件夹，双击 ManufacturerRadar.exe。
适用 Windows 10/11 64 位，无需安装 Python、无需 API Key。请保留 _internal 文件夹。

二、先识别厂家，再收录
输入产品、行业或公司名称，例如“水处理设备厂家”“豆腐机厂家”。
输入“水处理”“豆腐机”等产品/行业词时，搜索自动补上“厂家”意图，减少百科资讯；已有厂家、公司全称等条件时保留原关键词。
软件检索百度、搜狗、360、Bing、头条搜索、神马搜索，每个引擎主关键词最多前 3 页。
搜索结果仅作为候选链接保存，不能直接显示成厂家。
软件必须打开目标网页，读取页面中的厂家全称、相关主营/产品和主体证据，识别成功后才显示厂家卡片。
卡片包括名称、主营、地区、公开电话（有则显示）、资料评分及厂家页面链接。
缺电话不一定排除厂家；主体或业务无法确认的页面不收录为厂家。
百科、资讯、问答、搜索中转页、泛目录/多公司排名页及无关产品页面会被排除。
单个厂家自己的官网、商铺或B2B详情页，在可以确认主体、相关产品和自身生产/制造依据时可收录。
单纯贸易经销、维修保养或平台推荐的其他商家，不作为生产厂家收录。
“已读取厂家页”只表示实际读取并完成规则识别，不代表工商认证或信用担保。

三、查看资料与采集过程
“查看厂家页面”打开实际读取并识别的厂家网页。
“复制链接”复制该网页的URL。
“联系与资料”展示主营、电话、地址、收录依据、评分原因、原始搜索链接和全部证据。
“采集记录”单独列出候选链接及已识别/未收录/访问失败/待识别原因，不计入厂家数量。
广告仅在搜索页出现明确广告/推广标签时标记；广告未标识不代表不是广告。
主界面支持按名称、主营、地区、电话筛选，并可按评分或电话排序。

四、时间与范围
默认总时限120秒，可在搜索设置选择60/180/300秒。
最多30%时间用于搜索，剩余时间主要用于打开网页识别厂家，最后为负面补查预留少量时间。
每轮最多访问120个不同候选URL；同一URL在不同引擎出现时保留全部原始出处。
可选补读同一厂家最多2个联系/关于页面，以补充公开电话。
达到时限或点击停止后，保留已经实际读取并识别成功的厂家。
未处理的候选不会虚增厂家数量，可点击“继续识别候选页”继续处理。
网络请求默认超时8秒；连接、TLS与读取正在等待时可能有少量收尾延迟。
结果与数量随关键词、网络、地区和时间变化，软件不保证固定家数。

五、评分和负面
评分反映已采集资料的完整度及待核实负面线索，不是企业信用或质量评级。
已读取厂家详情页并识别主体 +30；厂家全称 +20；主营证据 +15；地区/地址证据 +5；
有公开电话及出处 +15；名称出处 +5；原始引擎与页码记录 +5；多引擎来源 +3；完成负面检查 +2。
每个不同URL的待核实负面指称 -15，最多扣30，最终分数限制在0—100。
未读取目标网页的搜索候选最高25分，但不会显示为厂家卡片或进入厂家表格导出。
默认最多12家已识别厂家补查同名负面，每家查询第1页；其他厂家保留“未检查”状态。
负面状态分为：未检查、检查受限、本轮未发现、发现待核实线索。
“本轮未发现”仅限实际执行的有限查询，不能推断没有负面信息。
负面指称附同名原文、链接和时间，必须人工核对来源、主体及内容真实性。

六、引擎受限与导入
验证码、动态内容、访问限制或网页改版可能导致候选搜索或厂家页面读取失败。
软件记录实际完成的搜索页数和访问失败原因，不绕过验证码或登录限制。
“导入搜索页”：在浏览器正常打开对应引擎前1—3页，完成所需验证，用Ctrl+S保存为HTML后导入。
导入只增加候选，随后仍须打开候选厂家网页识别，不能直接把搜索标题收录为厂家。
旧版v1.0历史中的未读网页记录也会回到候选，可点击“继续识别候选页”。

七、保存与导出
实际搜索结束后自动保存本地历史。厂家与候选采集记录分开保存。
“导出厂家”导出当前筛选中的已识别厂家，可选Excel、CSV或JSON。
Excel保留汇总、主营/地区/详情页/收录依据、搜索记录、证据、评分说明；CSV使用UTF-8 BOM。
JSON同时保留完整候选与采集过程记录。表格已对不可信文本做公式注入保护。
数据在程序旁data文件夹，目录不可写时改用%LOCALAPPDATA%\ManufacturerRadar\data。
保留旧data文件夹即可保留历史；请不要在复制新版文件时覆盖已有历史数据库。
演示模式全部为虚构数据，用来展示卡片和资料，不用于证明真实采集覆盖。

快捷键：Enter查找；Ctrl+F聚焦搜索；Ctrl+E导出厂家。
